Тип: мод (клиентский + серверный)
Авторство: 123new
Совместим, тестировался и проверялся на чистых версиях игры: 1.14,1.15,1.16,1.17,1.18,1.19

Описание:
Мод, добавляющий  'затемняемые' (для локального игрового мира игрока) зоны в обозначенных на карте зонах. Можно настраивать точки на карте, радиус зоны, коэфициент затемнения, вхождение игрока в диапазон тех или иных координат, а также нахождение игрока на тех или иных поверхностях. Мод требуется к наличию игрокам и является клиент-серверным. В чисто серверной связке не работает!!!
Идея по детекту игрока и затемнению игрового мира взята с мода Namalsk.
 
Видео-демонстрация работы на локальном сервере:
https://www.youtube.com/watch?v=9-06OMOF_As&feature=emb_imp_woyt
 
Возможности:
    'Затемняемые' (или ночь) локально у каждого игрока на экране при входе игрока в зону и нахождении в ней.
    При выходе игрока из зоны "затемнение" снимается.
    Можно совмещать несколько зон в одном месте с разными радиусами
    Настройки мода вынесены в json-конфиг мода, позволяющий быстро настроить нужное количество зон вам быстро и непритязательно.
    При ошибках в конфиге мода он будет пересоздан автоматически на стандартный, при этом ошибки будут отмечены в script-логе сервера. Рекоммендуется держать копию конфигурации и наблюдать за логами сервера после его старта!
    Возможность задать для каждой точки свои настройки.

Важно:
Скрипт проверен на чистой версии игры версии игры на момент публикации и является работоспособным по сей день и час.

Особенности работы:
    Чтобы работал ПНВ достаточно установить зону затемнения не на полный 0.00 а на хотя бы 0.005
Известные проблемы:
    Наблюдаются проблемы с отображением света от костров и факелов в затемняемой зоне. Исправление пока не найдено!
	
Важно:
Для определения игрока как 'в зоне затемнения' используются 2 варианта работы скрипта, или по вхождению игрока в радиус, или по вхождению игрока в диапазон координат в указаннгых границах. Подробнее об этом ниже в настройках!
Не ставьте коэфициент затемнения как 0.000 - он отключит работу прибора ночного видения. Установите хотя бы 0.005, это позволит достичь и приемлемой картинки, и оставит прибор рабочим. Это не исправляется.
Модификация не выставляет внутриигровое клиентское время для игрока как 'ночное'. Он симулирует затемнение экрана, создавая видимость наступления темного периода времени в отдельно взятой зоне на карте. Следует это понимать при работе на сервере!

Настройкa:
Параметр DebugLogs_Enabled- включает ведение дополнительного логирования для отслеживания работы скрипта (в том числе и на клиентской стороне). Формат значений - 1 - включено, 0 - выключено.
Параметр ZonesList - массив из конфигураций элементов с настройками зон. Минимум 1 элемент обязательно должен быть.
Параметр Comment - поле для ваших внутренних пометок. Не учавствует в работе скрипта. Можно указать любой свой текст.
Параметр Position_map - точка на карте в формате X Y Z (Y - высота) в которой будет центр зоны. Все 3 значения чувствительны к правильности. Будьте внимательны, если ошибетесь с высотой, дистанция будет считаться от указанной вами точки на высоте. Формат значений - числа с точкой больше 0, разделенные запятой.
Параметр Enable_detect_to_Radius - включает и отключает учет статуса игрока в зоне по указанному в параметре Radius радусу зоны. Формат значений - 1 - вкл, 0 - выкл
Параметр Radius - дистанция от центра Position_map .  В этом радиусе будет работать 'затемнение'. Проще говоря, если дистанция от центра зоны до игрока меньше или равна этому радиусу, то считается, что игрок в зоне. Указывается число, которое больше нуля. Параметр НЕ работает совместно с другими включенными настройками. Формат значений - число с точкой.
Параметр Enable_detect_in_X - включает и отключает учет статуса игрока в зоне по указанным в параметрах Coord_x_min и Coord_x_max значениям координаты X. Параметр может работать совместно с другими включенными настройками. Формат значений - 1 - вкл, 0 - выкл
Параметр Coord_x_min - значение начального диапазона координаты X на карте для учета игрока.  Проще говоря, если координата X у игрока больше или равна этому значению, то считается, что игрок в зоне. Указывается число, которое больше нуля. Работает только при Enable_detect_in_X =1. Формат значений - число с точкой.
Параметр Coord_x_max- значение кончного диапазона координаты X на карте для учета игрока.  Проще говоря, если координата X у игрока меньше или равна этому значению, то считается, что игрок в зоне. Указывается число, которое больше нуля. Работает только при Enable_detect_in_X =1. Формат значений - число с точкой.
Параметр Enable_detect_in_Y - включает и отключает учет статуса игрока в зоне по указанным в параметрах Coord_Y_min и Coord_Y_max значениям координаты Y.  Параметр может работать совместно с другими включенными настройками. Формат значений - 1 - вкл, 0 - выкл
Параметр Coord_Y_min- значение начального диапазона координаты Y на карте для учета игрока.  Проще говоря, если координата Y у игрока больше или равна этому значению, то считается, что игрок в зоне. Указывается число, которое больше нуля. Работает только при Enable_detect_in_Y =1. Формат значений - число с точкой.
Параметр Coord_Y_max- значение кончного диапазона координаты Y на карте для учета игрока.  Проще говоря, если координата Y у игрока меньше или равна этому значению, то считается, что игрок в зоне. Указывается число, которое больше нуля. Работает только при Enable_detect_in_Y =1. Формат значений - число с точкой.
Параметр Enable_detect_in_Z- включает и отключает учет статуса игрока в зоне по указанным в параметрах Coord_Z_min и Coord_Z_max значениям координаты Z. Параметр может работать совместно с другими включенными настройками. Формат значений - 1 - вкл, 0 - выкл.
Параметр Coord_Z_min- значение начального диапазона координаты Z на карте для учета игрока.  Проще говоря, если координата Z у игрока больше или равна этому значению, то считается, что игрок в зоне. Указывается число, которое больше нуля. Работает только при Enable_detect_in_Z=1. Формат значений - число с точкой.
Параметр Coord_Z_max- значение кончного диапазона координаты Z на карте для учета игрока.  Проще говоря, если координата Z у игрока меньше или равна этому значению, то считается, что игрок в зоне. Указывается число, которое больше нуля. Работает только при Enable_detect_in_Z=1. Формат значений - число с точкой.
Параметр Coeficient_light - значение коэфициента 'светлости' игрового мира.  Чем меньше укажете - тем темнее будет. Параметр крайне чувствителен к значениям. Например, при 0.00 будет кромешная тьма, при 0.05 будет вечер. Указывается число, которое больше или равно нулю. Формат значений - число с точкой.
Параметр Enable_detect_SurfaceTypeUnderPlayer - включает и отключает учет статуса игрока в зоне по указанным в параметре SurfaceTypes значениям поверхностей. Параметр может работать совместно с другими включенными настройками. Формат значений - 1 - вкл, 0 - выкл.
Параметр SurfaceTypes - параметр-массив со списком типов поверхностей, на которых игрок будет считаться как вошедшим в зону при условии, если он находится на данном типе поверхности. Проще говоря, если игрок стоит на этом типе поверхности внутри зоны, то считается, что игрок в зоне. Работает только при Enable_detect_SurfaceTypeUnderPlayer =1. Формат значений - текст в кавычках. Значения разделять через запятую 
Параметр IsDisableWorkZone_In_NightTime - параметр, отключающий работу затемняемой зоны в игровое ночное время (ночью и так темно, зачем затемнять экран?). Значения: 0 - выключено, 1 - включено. При выключении зона будет работать всегда без ограничений!  При включении ОГРАНИЧИВАЕТ и ОТКЛЮЧАЕТ работу параметра Enable_NightZone_OnlyInActiveTime_At_GameWorld и ListInGameActiveTime.
Параметр IsDisableWork_NVG_Item_In_Zone - параметр, отключающий работу Прибора ночного видения (ПНВ) внутри зоны. Значения: 0 - выключено, 1 - включено. При включении прибор ночного видения будет отключаться при входе в зону! (внимание, особенность: после выхода из зоны игроку для повторного включения прибора потребуется двукратная попытка включения прибора зажатием клавиши. С первого раза не сработает!) 
Параметр Enable_NightZone_OnlyInActiveTime_At_GameWorld - параметр, включающий работу затемняемой зоны исключительно в промежутке в зависимости от игрового времени. Значения: 0 - выключено, 1 - включено. При выключении зона будет работать всегда без ограничений! При включении будет использованы промежутки из параметра ListInGameActiveTime.
ListInGameActiveTime - параметр-массив со списком настроек игрового времени для включения и выключения работы зоны при Enable_NightZone_OnlyInActiveTime_At_GameWorld = 1. Требуется хотя бы 1 элемент, даже если опция отключена!
Параметр Start_Hour - Стартовое Время в часах, когда зона будет работать. Допустимые числа от 0 до 23. Работает только при Enable_NightZone_OnlyInActiveTime_At_GameWorld = 1
Параметр Start_Minute - Стартовое Время в минутах, когда зона будет работать. Допустимые числа от 0 до 59. Работает только при Enable_NightZone_OnlyInActiveTime_At_GameWorld = 1
Параметр End_Hour - Время окончания работы зоны в часах, когда зона еще будет работать. Допустимые числа от 0 до 23. Работает только при Enable_NightZone_OnlyInActiveTime_At_GameWorld = 1
Параметр End_Minute - Время окончания работы зоны в минутах, когда зона еще будет работать. Допустимые числа от 0 до 59. Работает только при Enable_NightZone_OnlyInActiveTime_At_GameWorld = 1
Указываемое время во всех последних 4 параметрах указывается в 24-х часовом формате, где 00:00 - минимальное значение, 23:59 - максимально возможное значение. Если требуется указать время в часах или минутах, где первая цифра 0, например, 05:07, то значение 0 в параметре не указывается (т.е. будет вот так ActiveTime_GameWorld_Hours_Start = 5 ActiveZone_Time_GameWorld_Minutes_Start = 7).
