# Silver_77_Zones — приоритетная задача

Этот файл обновляется каждый раз, когда фактическая следующая приоритетная задача проекта меняется. Историю здесь не хранить и документ не раздувать дальше текущего продолжения.

## ПРИОРИТЕТ №1

Заложить первый canonical config pipeline `Silver_77_Zones`:

- собственный profile JSON;
- минимальные Lighting-параметры;
- отдельные save / backup / profile paths;
- основу второй вкладки «Зоны» в существующем Workshop.

Первые Lighting-настройки:

- `OuterRadius` — начало воздействия;
- `InnerRadius` — полный эффект;
- `MaxLightingLerp` — максимальная сила User Lighting от 0 до 1.

На следующей технической задаче сначала повторно определить точный canonical dev path и `$profile:` path, а затем создавать JSON, чтобы не получить два источника правды.

После первого JSON/Web vertical slice следующая проверка — сборка Client PBO и runtime User Lighting.
