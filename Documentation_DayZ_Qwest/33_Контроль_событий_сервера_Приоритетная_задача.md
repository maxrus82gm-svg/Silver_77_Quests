# Контроль событий сервера — приоритетная задача

Контроль событий сервера и Map пока являются одной общей веткой. Этот файл содержит только её следующую фактическую цель и обновляется после смены приоритета.

## ПРИОРИТЕТ №1

Превратить существующую read-only карту в первый spatial editor.

Первый editable adapter — `Silver_77_Migrate`, потому что система уже имеет canonical config с точками, маршрутами, целями и несколькими spatial radii. На ней нужно проверить универсальную архитектуру Map Editor до подключения Quest, Zones и других систем.

Общий поток данных:

```text
SOURCE SYSTEM
    ↓
MAP ADAPTER
    ↓
MapFeature / visual representation
    ↓
spatial editing
    ↓
MAP ADAPTER
    ↓
SOURCE SYSTEM
```

Map не создаёт скрытый собственный source-of-truth. Каждая подключённая система сохраняет свой canonical owner.
