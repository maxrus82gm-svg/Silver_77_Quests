# Единая система проекта

`Silver_77_Quests` развивается как единая расширяемая система для создания игровых сценариев и управления связанными данными DayZ-сервера. Её направления имеют собственную реализацию и документацию, но решают части одной общей задачи.

## Основные направления

- Квестовая система — создание, редактирование и выполнение квестов: Quest Client / Server, интерфейс игрока и Quest Editor `JSON_Quvest`.
- `Silver_77_Migrate` / Миграция — server-side исполнение миграционных групп и событий: spawn, маршруты, цели и поведение групп. В будущем её смогут запускать квесты и другие системы.
- `Silver_77_Zones` — единое описание игровых зон и их Visual, Audio, Hazard, заражения, радиации, защиты и других компонентов вместо нескольких разрозненных настроек одной территории.
- Контроль событий сервера — фактический слой знаний об объектах, территориях, зонах, spawn points, маршрутах и источниках данных для будущей интерактивной карты.

## Как они связаны

Контроль событий сервера даёт общую фактическую основу мира. Квесты используют её для игровых сценариев, Zones — для условий и свойств территорий, Migration — для динамических групп и событий. Эти направления могут обмениваться командами и данными, сохраняя собственные границы ответственности.

## Единый Web Workshop

Перспективная общая точка управления — единый Web Workshop / Web-интерфейс с независимыми разделами Quest, Migration, Zones и Server World / Events / Map.

Единый Web-интерфейс не означает один монолитный runtime-мод: игровые системы могут оставаться изолированными, а Web Workshop служит общей оболочкой редактирования и управления.

Структура открыта для новых самостоятельных направлений, которые в будущем смогут подключаться к общей системе и Web Workshop.
