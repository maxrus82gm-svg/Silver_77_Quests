# 04_Архитектура

Здесь храним общую архитектуру проекта: как связаны редактор, JSON, клиент, сервер, UI и правила агента.

## Основные части проекта

### Клиентский мод

Папка:
`Silver_77_Quests_Client`

Отвечает за:
- клиентский UI;
- отображение квестов;
- клиентскую часть синхронизации;
- взаимодействие игрока с интерфейсом.

### Серверный мод

Папка:
`Silver_77_Quests_Server`

Отвечает за:
- серверную логику квестов;
- проверку условий;
- выдачу наград;
- сохранение прогресса;
- обработку действий игрока.

### Редактор квестов

Папка:
`JSON_Quvest`

Отвечает за:
- создание и редактирование JSON-квестов;
- dev-данные;
- справочники item class names.

### Документация и правила

Папка:
`Documentation`

Важные документы:
- `Documentation/AGENT_TASK_LOOP.md`
- `Documentation/SplitDoc/START.md`
- `Documentation/SplitDoc/GIT_REVIEW_RULES.md`
- `Documentation_DayZ_Qwest` — Obsidian-база памяти проекта

## Принцип работы с агентом

ChatGPT выбирает минимальный набор правил и документов.

Агент читает:
- `AGENT_TASK_LOOP.md`;
- `START.md`;
- только нужные тематические `SplitDoc`;
- нужные файлы из `Documentation_DayZ_Qwest`, если они указаны в задаче.
