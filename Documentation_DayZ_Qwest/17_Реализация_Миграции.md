# Реализация миграции

Краткая карта состояния проекта. Наличие реализации не означает, что каждая возможность уже прошла отдельный runtime-тест.

Центральный документ: [[14_Квест_Миграция]].

## Реализовано

- Server-only создание vanilla infected с физическим движением по navmesh-маршруту.
- Произвольные `routePoints` и стабильный индивидуальный formation offset вдоль маршрута.
- Масштабируемые независимые spawn/target formations с настраиваемыми spacing и jitter.
- Одновременные и повторные runtime-группы с `groupId` и уникальным `runtimeGroupId`.
- Vanilla aggro handoff и возврат к migration-маршруту после `CALM`.
- Индивидуальный stuck detector и Route Progress Watchdog.
- Направленный recovery stimulus, проверка результата и reverse escape без teleport.
- Опциональные процентные route/final AI-stimulus zones с rearm.
- Final hold со свободным vanilla AI и возвратом вышедших за hold radius.
- Отдельный настраиваемый lifetime каждой GROUP.
- Управляемое server-side логирование и подробная stuck/recovery диагностика в `$profile`.
- Глобальный погодный transition и storm ramp с group-level запросом погоды.
- Unified `MigrationConfig.json` с legacy in-memory compatibility без перезаписи profile.
- Базовая архитектура `GROUP / EVENT / ACTIVATION` и public server-side API.
- Group-level `spawnChancePercent` и независимый chance roll перед fresh GROUP/EVENT launch.
- Repository build-wrapper с эталонной Support-копией canonical config вне PBO.

## Планируется

- Group-level persistence живых active/`RELEASED` members через A/B snapshots.
- Persistent counters, limits и cleanup migration infected.
- GLOBAL EVENT DIRECTOR со scheduler/random cadence, cooldown, quota и online-check.
- Безопасная обработка нескольких STARTUP activations.
- Loop/patrol-маршруты.
- Индивидуальные правила поведения и release для route points.
- Настройка дальности и силы AI stimuli.
- Масштабирование GROUP по игрокам возле нужной области.
- Специальный migration loot и выбор infected по CE-территории.
- Оповещение «Зенит сообщает» и отдельная слышимая атмосфера события.
- Weather hold/recovery/tuning и исследование tint неба.
- PRESET и request-only LaunchContext с разрешёнными overrides.
- Quest → Migration bridge без переноса migration-механик в Quest-мод.
- Shared multiplayer encounter с защитой от duplicate spawn.
- Web-редактор MigrationConfig и общий DayZ clipboard parser координат.
