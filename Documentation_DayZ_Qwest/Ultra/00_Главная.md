# Ultra

Каноническая документационная основа вспомогательного субагента Ultra внутри проекта `Silver_77_Quests`.

## Порядок работы

[[00_Главная]]
→ [[01_Старт_Ultra]]
→ [[02_Правила_Ultra]]
→ [[03_ULTRA_TASK]]
→ [[04_ULTRA_REPORT]]

- `01_Старт_Ultra.md` и `02_Правила_Ultra.md` содержат постоянный контекст и правила.
- `03_ULTRA_TASK.md` содержит одноразовый launch-payload текущего запуска, который Codex полностью формирует непосредственно перед вызовом Ultra. Пользователь вручную этот файл не поддерживает.
- `04_ULTRA_REPORT.md` содержит результат последнего запуска Ultra.

Ultra не запускается автоматически при чтении этих документов.
