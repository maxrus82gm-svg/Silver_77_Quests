# Рабочий вход ChatGPT-координатора — Silver_77_Quests

**Назначение:** организация подготовки TASK, независимой проверки результатов других агентов, архивирования и закрытия итераций. Не является второй карточкой Codex или копией технического регламента Web Alarm Ultra.

**Нормативные владельцы DayZ:** `20_SplitDoc/TASK_PREPARATION_RULES.md`, `CONTEXT_ROUTING.md`, `TASK_LIFECYCLE_RULES.md`, `GIT_REVIEW_RULES.md`, `DOCUMENTATION_RULES.md`. Файлы `12_Старт.md` и `11_Задачи_Codex.md` — старт и персональная карточка исполнителя.

## Навигация Obsidian — намеренные связи

- [[42_TACTICAL_CONTEXT|Тактический контекст]] — текущие решения, OPEN и точка возобновления.
- [[11_Задачи_Codex|Карточка Codex]] — назначение исполнителя, сдача и проверка.
- [[07_Реестр_задач|Общий реестр TASK]] — тематический указатель по всей истории, без обязательного чтения архива.
- [[10_Правила_агента|Правила агента]] — действующие пути и организационные правила DayZ.

Очередь и незакрытые FOLLOWUP по-прежнему ведутся в `05_Очередь_задач.md`; это не архив всех TASK. Обоснованные графовые связи собраны только в этом навигационном разделе, а внутри процедур используются текстовые адреса.

## Цикл координатора

| Ситуация | Действие | Проверяемый результат |
| --- | --- | --- |
| Новый чат | Адресно прочитать `42_TACTICAL_CONTEXT.md`, все текущие OPEN/FOLLOWUP в `05_Очередь_задач.md` и состояние БЛОКА 1 Codex | Известны TASK, ответственные, ограничения, фактический NEXT; недоступное = UNKNOWN |
| Новое поручение | Проверить активные TASK/FOLLOWUP, зависимости и точный scope | Три блока **в чате**: полная постановка для пользователя, краткий активатор, пояснение ожидаемого результата |
| Работа продолжается | Не менять замороженный БЛОК 1; уточнения оформлять отдельными AMENDMENT | Полный источник и поправки имеют происхождение |
| Финальная сдача | Проверить точную TASK, report/manifest/evidence, публикацию и result SHA | Авторский RESULT READY/PARTIAL/REVISE не объявлен PASS |
| Механическая ротация | Проверить архив предыдущего 1.1, полный task snapshot и report; запустить `Tools/task_slot_rotate.py`: check → dry-run → разрешённый apply | БЛОК 1.1 хранит точную постановку; БЛОК 1 освобождён; ROTATED ≠ VERIFIED |
| Независимый review Codex | Сверить TASK/AMENDMENT → report → фактический diff/files/evidence | Вердикт привязан к точному SHA, scope, NOT RUN, обнаруженным проблемам |
| Закрытие итерации | Сохранить полный пакет/локатор и readback в `001_История_задач_Codex.md`; OPEN в №05; краткий результат в `TASK_HISTORY.md`, NEXT в №42 | Честный PASS/REVISE/PARTIAL и незавершённые FOLLOWUP; не подменять продуктовый PASS документальным закрытием |
| Перед новой TASK / сменой чата | Снова сверить №05/FOLLOWUP и №42 | Никто не теряет незавершённые пункты при смене чата или исполнителя |

## Права на GitHub и проверки

Пользователь разрешил ChatGPT-координатору самостоятельно готовить документные исправления, проверки и безопасный CI **в ветке `GPT_Dayz`**. Пользователь отдельно проверяет и объединяет `GPT_Dayz` → `main`. Codex/Claude не получают Git/GitHub-права по наследству — им требуется прямое адресное разрешение. Канон: `20_SplitDoc/GIT_REVIEW_RULES.md` → раздел 1.1.

Наличие GitHub Actions не означает выполнение тестов: указывать реальный run/status/exit, NOT RUN. Безопасный CI использует синтетические данные, не ротирует реальные TASK и не запускает DayZ. Личный коммит ChatGPT и собственный тест **не являются независимой приёмкой собственной правки**: нужен другой reviewer или явная пользовательская приёмка в обозначенной области.

## История и граф

- №05 — текущие TASK, очередь и FOLLOWUP; №07 — тематический указатель по всем историческим и новым TASK (пока его старые записи не сверены, он не считается полным). `ASSIGNED`, `FIX_REPORTED` и новый successor не закрывают OPEN; для закрытия нужны evidence/независимая проверка либо отдельное принятие остаточного риска.
- №42 — оперативный срез (ориентир около 20 тыс. символов, не жёсткий предел). Полные TASK, AMENDMENT, отчёты и исторические тексты остаются у соответствующих владельцев. Историю читать адресно.
- В Obsidian **ссылки в двойных квадратных скобках используются исключительно для намеренно видимых графовых связей**, главным образом в `00_Главная.md` и профильных навигационных индексах. В описательных документах давать обычные имена/пути в backticks, не создавать случайные линии графа ссылками «см. файл».
- Старые смысловые связи и якоря сохранять либо переносить по проверяемой матрице; случайные новые ребра удалять. `Task_Reports`, `Ultra`, архивы и старые точки входа сохранять физически, но исключать из рабочего графа. Настройки графа не равно живой GUI-проверке — визуальный итог подтверждает пользователь.
- Назначение новой TASK принадлежит пользователю. ChatGPT отвечает за собственные полномочия и не присваивает себе независимый PASS по собственным исправлениям.

Архитектура, интеграция и глобальный план остаются за DayZ №30/38/39; организационное заимствование каркаса не переносит Web Alarm runtime или чужие технические роли.
