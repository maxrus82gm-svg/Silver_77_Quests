------------------------------------------------------------
2. DETACH / ВТОРОЙ МОНИТОР
------------------------------------------------------------

Желательно иметь:

[Открепить карту]

После нажатия Map открывается отдельным browser window.

Пользователь может вручную перенести это окно на второй монитор.

Основной Workshop при этом:

- не сжимается;
- не перестраивает Quest UI;
- продолжает работать на первом мониторе.

Detached Map продолжает быть интерактивной.

Нужно определить технически правильный способ синхронизации окон.

НЕ считать заранее, что JSON polling является правильным решением.

Рассмотреть варианты:

- shared in-memory state;
- event bus;
- window.opener;
- postMessage;
- BroadcastChannel;
- server-mediated state;
- другой более правильный механизм.

Сравнить варианты.

Учесть:

- браузер;
- same-origin local server;
- закрытие одного окна;
- повторное открытие;
- reload;
- dirty state;
- reconnect;
- потерю unsaved изменений.

------------------------------------------------------------
3. JSON НЕ КАНАЛ СВЯЗИ МЕЖДУ ОКНАМИ
------------------------------------------------------------

Текущая идея:

JSON должен оставаться persistence / canonical data,
а не постоянно перечитываться после каждого клика
как механизм синхронизации UI.

Изменение поля в Editor
должно быстро отображаться в Map.

Изменение spatial value в Map
должно быстро отображаться в Editor.

Save уже потом фиксирует изменения
в canonical source конкретной системы.

Проверить эту идею.

------------------------------------------------------------
4. ACTIVE MODULE CONTEXT
------------------------------------------------------------

Workshop должен знать:

activeModule = Quest / Migration / Zones / Map / ...

Detached Map должна понимать,
с какой системой сейчас работает основной Workshop.

Например:

activeModule = Quest

тогда:

- Quest features доступны для работы;
- выбранный Quest выделяется;
- другие слои могут оставаться видимыми как context/reference;
- Migration / Zones не обязательно скрывать полностью;
- но они не должны случайно редактироваться.

Проверить,
нужен ли activeModule,
или существует более правильная модель.
