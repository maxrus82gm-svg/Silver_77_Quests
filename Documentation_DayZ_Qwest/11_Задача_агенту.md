- текущую задачу в `БЛОКЕ 1`;
- последний `AGENT REPORT` в `БЛОКЕ 2`;
- последний `REVIEW / STATUS` в `БЛОКЕ 3`;

RUNTIME GROUP IDENTITY:
- Каждый фактический `StartScenario()` создаёт новый `S77MigrateGroupState` и ID вида `scenarioId_RUN_N`.
- В group state хранится список только тех infected, которые успешно созданы данным spawn instance.

ALIVE DENOMINATOR / INSIDE COUNTER:
- Denominator — текущее число живых, корректных, ещё не `RELEASED` members конкретной runtime-группы.
- Убитые и released infected исключаются; vanilla/mod infected и members другой runtime-группы никогда не добавляются.
- Inside counter проверяет фактическое положение этих active members в горизонтальной X/Z-плоскости; Y не учитывается.
- Counting centers — raw `routePoint` и raw `targetPosition`; individual formation offset применяется только к navigation targets.
- Порог: `requiredCount = ceil(aliveActiveGroupCount * triggerPercent / 100)`; при наличии живых members минимум равен `1`.

ROUTE ACTIVATION:
- Для каждой runtime-группы и каждой route point хранится отдельный ARMED/TRIGGERED bool.
- При `inside >= required` ARMED-точка пишет event log, создаёт один world AI stimulus и disarm.
- Пока occupancy остаётся не ниже текущего порога, повторного stimulus на каждом update нет.
- При `inside < required` точка rearm; новый рост до порога создаёт новый импульс.
- Gameplay waiting timer и новый loop не добавлены: используется существующий route update с интервалом 250 ms.
- `routePointReachRadius = 6.0` остаётся индивидуальным navigation reach radius.
- `routeActivationRadius = 12.0` — общий counting radius.
- `routeActivationRadii[index]` задаёт optional radius отдельной точки; отсутствующее, короткое или неположительное значение использует общий fallback.
