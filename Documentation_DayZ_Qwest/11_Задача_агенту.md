WATCHDOG LOGIC:
- Добавлен второй индивидуальный detector только для `MIGRATION` и `RETURN_TO_HOLD`.
- Каждый infected сравнивает X/Z-distance именно до `GetCurrentRouteTarget(state)`: до текущего manual route point с formation offset либо до собственного `m_MigrationTarget`, но не до navmesh waypoint.
- Формула окна: `progress = previousDistance - currentDistance`; нормальная проверка использует только world position, logical target, `HorizontalDistance()` и float-сравнения.

BACKTRACK DETECTION:
- Если `currentDistance - previousDistance >= 10.0 m` за одно окно, немедленно фиксируется `ROUTE_PROGRESS_LOST reason=BACKTRACK`.
- Лог содержит scenario, runtimeGroupId, infected ID, mode, logical target, previous/current distance, progress, backtrack и bad-check count.

NO-PROGRESS DETECTION:
- `progress >= 5.0 m` считается полезным и сбрасывает индивидуальный bad-check counter.
- При меньшем прогрессе counter увеличивается; два последовательных плохих окна дают `ROUTE_PROGRESS_LOST reason=NO_PROGRESS`.

DISTRIBUTED PERFORMANCE MODEL:
- Первый baseline каждого infected назначается с индивидуальным controlled jitter внутри одного окна `30 sec`; сравнение выполняется только после следующего полного окна.
- Отдельные `CallLater` для infected не создаются: используется существующий manager update cycle.
- `FindPath()`, navmesh sampling, group scan и stimulus отсутствуют в обычной проверке; `BuildPath()` вызывается только после подтверждённой проблемы и завершения recovery.

INDIVIDUAL STATE:
- В `S77MigrateUnitState` отдельно хранятся baseline validity, previous distance, next check time, bad-check count и stagger.
- Baseline сбрасывается при spawn/новом `BuildPath()`, смене route point, AGGRO, recovery, `HOLD_FREE`, возврате, release и смерти.

RECOVERY REUSE:
- После подтверждённого нарушения переиспользуется существующий directed recovery TASK 139, направленный к logical route target.
- Manager снимает overrides, создаёт AI-only stimulus, предоставляет vanilla freedom и ждёт `target == null`, `CALM` и cooldown; затем выполняется новый `BuildPath()` от актуальной позиции.

NATURAL AGGRO SAFETY:
- Быстрый vanilla target/mind check в `MIGRATION` и `RETURN_TO_HOLD` не менялся.
- В `AGGRO`, `STUCK_RECOVERY`, `HOLD_FREE` и `RELEASED` watchdog не выполняется и не перебивает vanilla AI.
