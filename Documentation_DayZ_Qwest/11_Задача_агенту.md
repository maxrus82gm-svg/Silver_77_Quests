- текущую задачу в `БЛОКЕ 1`;
- последний `AGENT REPORT` в `БЛОКЕ 2`;
- последний `REVIEW / STATUS` в `БЛОКЕ 3`;

AGENT REPORT

TASK:
- `TASK 144 — Индивидуальный recovery stimulus: каждый застрявший infected должен срабатывать сам`.

STATUS:
- `IMPLEMENTED / WAITING FOR RUNTIME`.
- Git write-команды не выполнялись.

ROOT CAUSE CONFIRMED:
- `TriggerStuckRecovery()` вызывал `ReleaseNearbyStuckMembers()`, который заранее переводил соседних stalled infected в `STUCK_RECOVERY` без их собственного trigger.
- `S77MigrateRecoveryStimulusRecord` и spatial lookup по runtime group / position могли блокировать own stimulus другого infected через `localCooldownActive`.

INDIVIDUAL RECOVERY:
- Только infected, который сам получил `STUCK_DETECTED` либо `ROUTE_PROGRESS_LOST`, вызывает `BeginStuckRecoveryState()` для собственного state и делает одну попытку directed stimulus.
- `TriggerStuckRecovery()` принимает `cause=STUCK` или `cause=ROUTE_PROGRESS_LOST`; внутри одного `STUCK_RECOVERY` detectors не выполняются, поэтому повторного stimulus spam нет.

SHARED FORCED RECOVERY REMOVED:
- Вызов и функция `ReleaseNearbyStuckMembers()` удалены полностью.
- `IsUnitStalledAtSample()` удалён как оставшийся без использования helper.
- Один infected больше не меняет recovery state другого infected и не сбрасывает его индивидуальные detector samples.

SPATIAL SUPPRESSION REMOVED:
- Удалены `S77MigrateRecoveryStimulusRecord`, `m_RecoveryStimuli`, constructor/Stop lifecycle, `FindRecoveryStimulusRecord()`, `PruneRecoveryStimuli()`, insert/search/prune и cooldown branch.
- Удалены устаревшие runtime-логи `STUCK_RECOVERY_SHARED`, `STUCK_RECOVERY_RETRY` и `localCooldownActive`.
- Nearby stimulus другого infected больше не может подавить own stimulus нового подтверждённого incident.

REPEATED RECOVERY:
- После vanilla freedom, `target == null`, `CALM`, cooldown и нового `BuildPath()` samples создаются заново.
- Никакого lifetime-флага «уже использовал recovery» нет: новый реальный stuck того же infected запускает новый отдельный cycle и новый own stimulus.

ROUTE PROGRESS COMPATIBILITY:
- TASK 142 `BACKTRACK` / `NO_PROGRESS`, thresholds и distributed scheduling не менялись.
- Подтверждённый `ROUTE_PROGRESS_LOST` использует тот же индивидуальный recovery с `cause=ROUTE_PROGRESS_LOST` и прежним logical route target.
- TASK 141 остаётся `< 2 m X/Z displacement за 6 sec`; TASK 139 recovery timings и intent `MIGRATION` / `RETURN_TO_HOLD` сохранены.

NATURAL GROUP EFFECT:
- World AI stimulus остаётся обычным `NoiseSystem` stimulus, поэтому nearby infected по-прежнему могут естественно его услышать и начать двигаться.
- Такая реакция не меняет их manager recovery state; если сосед продолжает стоять, его собственный detector остаётся активным и позднее запускает собственный incident.

PERFORMANCE:
- Удалён full scan members при каждом stuck incident и удалён spatial recovery-record search/prune.
- Новые NoiseSystem calls возникают только после собственного detector trigger; scheduler, `CallLater` и per-tick group scan не добавлены.

CONFIG COMPATIBILITY:
- `S77MigrateConfig.c`, source `MigrationConfig.json` и runtime profile не изменялись.
- Legacy-поля `stuckStimulusShareRadius` и `stuckStimulusRetrySeconds` остаются в JSON/parser, поэтому существующие runtime-файлы продолжают загружаться; manager после TASK 144 их не использует.

LOGGING:
