WHAT IS PRESENT IN CODE:
- Каждый `StartScenario()` создаёт отдельный `S77MigrateGroupState` и уникальный `runtimeGroupId` вида `scenarioId_RUN_N`.
- В `groupState.m_Members` попадают только успешно созданные infected данного spawn instance.
- Denominator считается через `CountActiveGroupMembers()` только от members этой runtime-группы, которые живы и ещё не `RELEASED`.
- Killed infected, `RELEASED` infected, обычные vanilla infected и members других runtime groups в percentage не входят.
- Route/final counting использует горизонтальную X/Z distance к raw route point / raw `targetPosition`.
- `routePointReachRadius = 6.0` отвечает только за individual navigation segment; `routeActivationRadius = 12.0` и `routeActivationRadii[index]` отвечают за counting zone.
- Threshold считается как `ceil(aliveActiveMembers * triggerPercent / 100)` с minimum `1` и cap по alive count.
- Проверенные примеры: `10 -> 3`, `8 -> 3`, `7 -> 3`, `3 -> 1`, `1 -> 1`.

ROUTE ACTIVATION / REARM:
- Каждая route point каждой runtime-группы имеет собственный ARMED/TRIGGERED state в `m_RouteActivationArmed`.
- При `inside >= required` создаётся один world AI stimulus в raw route point, точка disarm.
- Пока occupancy остаётся не ниже threshold, spam-trigger не происходит.
- При `inside < required` точка rearmed; новый рост до threshold даст повторный stimulus.
- Отдельный gameplay waiting timer не добавлен: используется текущий update loop.

STIMULUS / VANILLA HANDOFF:
- Stimulus создаётся через `NoiseSystem.AddNoiseTarget(position, lifetime, NoiseParams, multiplier)`.
- Preset загружается из `CfgVehicles SurvivorBase NoiseShout`.
- Fake `SoundSet`/`SoundObject` и forced native `CHASE`/`FIGHT` отсутствуют.
- Nearby vanilla infected могут естественно услышать world stimulus, но не входят в counters.
- При `target != null` или mind state != `CALM` manager снимает overrides; после `target=null`, `CALM` и `5 sec` cooldown строит путь заново и продолжает migration.

FINAL / RELEASED:
- Final zone использует такую же percentage accumulation механику, default `30%` и `12.0` м.
- Final stimulus не вызывает `RELEASED` и не освобождает группу.
- `ReleaseUnit()` вызывается только из actual arrival paths конечного navmesh-маршрута.
- После `RELEASED` infected исключается из denominator/final counter и больше не получает migration path control.
