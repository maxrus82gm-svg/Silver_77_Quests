# Квестовая система — приоритетная задача

Этот файл содержит только следующую фактическую цель квестовой ветки. После смены приоритета текущее содержимое обновляется, а история здесь не накапливается.

## ПРИОРИТЕТ №1

Подготовить будущую интеграцию `Quest -> Silver_77_Migrate`.

Квестовая система должна иметь возможность инициировать уже существующий migration `EVENT` или `ACTIVATION`, не копируя runtime-логику миграции внутрь Quest-мода.

Граница ответственности:

- `Quest` определяет игровое условие, решает, когда требуется запуск, и передаёт идентификатор разрешённого migration request;
- `Silver_77_Migrate` валидирует запрос, проверяет chance/conditions, создаёт runtime group/event и управляет infected, маршрутом, recovery, lifetime, persistence и cleanup.

До практической реализации bridge необходимо стабилизировать и проверить соответствующую сторону `Silver_77_Migrate`.

Новый Quest JSON contract, новое поле квеста и сам bridge в текущем приоритете не утверждаются и не реализуются.
