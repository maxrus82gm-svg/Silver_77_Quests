# Общий реестр задач Silver_77_Quests

**Назначение:** единый тематический указатель по ВСЕМ известным TASK проекта DayZ — историческим, текущим, завершённым, отложенным и требующим проверки. Это не очередь исполнения и не копия полного архива. Владелец актуализации — ChatGPT-координатор.

**Состояние на 01.11.2026:** навигационный каркас создан; полная ретроспективная сверка задач ещё НЕ выполнена. Отсутствие строки здесь не означает, что TASK не существовала. Никакие старые статусы или даты не подтверждаются этим каркасом автоматически.

## Принцип выборочного чтения

1. Сначала искать направление в тематическом указателе, затем конкретный TASK ID; не читать весь журнал при каждом новом чате.
2. Каждая задача имеет один основной идентификатор и один канонический реестровый адрес; допускается несколько тематических меток без дублирования самой записи.
3. Для каждой задачи указывать: TASK ID, дата (или UNKNOWN), направление, одна–три фразы о цели и результате, исполнитель (если доказан), независимый статус (или UNKNOWN/STATUS_CONFLICT), связанные TASK/FOLLOWUP, точный локатор полного источника.
4. Рабочая глубина: **не менее 50 последних задач с содержательными аннотациями**, а при длинной связанной теме — больше. Последние **5** можно описывать подробнее; следующие до 50 — компактно; более старые — индексной записью. Это ориентир объёма представления, не предел хранимой истории.
5. При появлении следующей TASK вытесняемая из расширенного окна запись сокращается **один раз** только после проверки постоянного источника. Нельзя повторно сжимать уже сжатую запись или удалять уникальные решения, открытые проблемы и ограничения.
6. Полные постановки, AMENDMENT, отчёты, независимые проверки и доказательства не сокращаются и остаются в своих постоянных архивных источниках.

## Реестр TASK по ID

Постепенно заполняется **только по проверяемым источникам**, без догадки о пропущенных номерах. Пока ни одна старая TASK не импортирована сюда как установленный факт.

**Формат записи:** `TASK ID | дата | тема / направление | результат | статус и область проверки | связанные TASK/FOLLOWUP | источник`.

## Разделение с действующими документами

- `05_Очередь_задач.md`: назначенные / ожидающие задачи, статусы, открытые FOLLOWUP и прежний backlog; не переименовывать и не удалять.
- `42_TACTICAL_CONTEXT.md`: оперативная память и текущий NEXT; не подменяет многолетнюю историю.
- `11_Задачи_Codex.md`: персональная карточка и точная текущая TASK; `001_История_задач_Codex.md`: полный долговременный архив Codex.
- `20_SplitDoc/TASK_HISTORY.md`: исторический журнал TASK, источник для адресного восстановления, а не готовый исчерпывающий нормализованный реестр.
- `Task_Reports/`, принятые снимки и Git-версии: доказательства по конкретным TASK, сохраняются без сокращения.

Этот файл намеренно **без wiki-ссылок**, чтобы не создавать графовые ветки по сотням исторических задач. Для навигации по Obsidian единственный вход в этот индекс — из `000_Задачи для агента.md`.
