# Идеи квеста миграции

Короткий рабочий список будущих направлений для `Silver_77_Migrate_server`. Подробности каждой идеи будут оформляться отдельно, когда пользователь выберет её для реализации.

Порядок пунктов не является приоритетом разработки.

1. **Offset/разлёт группы в профильный JSON** — вынести настройки плотности спавна и разброса конечных точек в конфиг сценария, чтобы менять поведение под конкретную территорию без перепаковки PBO.

2. **Масштабирование орды по игрокам возле цели** — увеличивать базовое количество infected на случайный бонус за каждого живого реального игрока возле `targetPosition`. Расчёт выполнять один раз непосредственно перед spawn группы.

3. **Несколько независимых миграций одновременно** — разрешить разным `scenarioId` работать параллельно, но не создавать новую группу одного сценария, пока жив хотя бы один infected его предыдущей группы.

4. **Финальная AI-активация** — при индивидуальном приближении примерно на 50 метров к своей цели каждый migration infected один раз получает AI stimulus. Подходящий vanilla API ещё нужно исследовать; принудительный `CHASE` / `FIGHT` без реальной цели не считается доказанным.

5. **Специальный лут migration infected** — добавить отдельный настраиваемый шанс предметов и их количества для каждого заражённого миграционной группы, не затрагивая обычных vanilla infected.

6. **Автоматический выбор типов infected по территории** — предусмотреть автоматический подбор заражённых по CE / infected territory и сохранить ручной список `infectedTypes` как отдельный режим.

7. **«Зенит сообщает»** — добавить атмосферное предупреждение игрокам о замеченной миграционной группе, районе её появления и приблизительном направлении движения.

8. **Persistence миграции после рестарта** — сохранять оставшихся в живых migration infected и после рестарта восстанавливать именно выжившую часть группы, а не создавать исходную группу заново.
