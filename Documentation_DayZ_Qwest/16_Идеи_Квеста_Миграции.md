# Идеи квеста миграции

## Назначение

Документ является накопительным списком идей, будущих улучшений и требований для системы `Silver_77_Migrate_server`.

Записи ниже не являются описанием уже реализованных функций. У каждой идеи отдельно указан её текущий статус.

## Идея 1. Два режима выбора типов заражённых

Статус:

- `ИДЕЯ`;
- `ТРЕБУЕТ ИССЛЕДОВАНИЯ`;
- `НЕ РЕАЛИЗОВАНО`.

В будущей конфигурации миграции предлагается предусмотреть два режима выбора типов заражённых.

### Режим 0 — автоматический

Условная настройка:

`infectedTypeMode = 0`

Миграционная система должна пытаться использовать типы заражённых, соответствующие vanilla-системе DayZ, Central Economy и infected territory в районе исходной точки миграции. Состав группы должен максимально соответствовать местности, из которой начинается миграция.

Точный способ получения через публичный Enforce API набора infected, соответствующего конкретной CE/infected territory, пока не известен и не подтверждён. Перед реализацией требуется отдельное исследование.

Также необходимо определить fallback для случая, когда точка миграции не относится к подходящей infected territory или публичный API не позволяет надёжно определить её состав.

### Режим 1 — ручной

Условная настройка:

`infectedTypeMode = 1`

Используется список классов из настройки `infectedTypes`. В этом режиме администратор сервера самостоятельно определяет, какие infected могут входить в миграционную группу.

Текущая тестовая система фактически работает по ручному принципу, но отдельное поле `infectedTypeMode` пока не реализовано.

## Идея 2. Дополнительный лут у миграционных заражённых

Статус:

- `ИДЕЯ`;
- `НЕ РЕАЛИЗОВАНО`.

В будущем предлагается предусмотреть специальный дополнительный лут только у заражённых, созданных системой миграции.

Возможные требования:

- каждый migration infected может иметь шанс получить дополнительный предмет;
- вероятность задаётся конфигурацией;
- пример значения `0.5` означает вероятность `50%`;
- одним из вариантов награды могут быть патроны;
- возможный пример — небольшое количество патронов 9 мм россыпью;
- позднее список можно расширить другими типами патронов и предметов.

Цель идеи: игрок, потративший боеприпасы на уничтожение миграционной группы, может получить часть расходников обратно как награду.

Конкретные class names патронов и предметов пока не выбраны. Механика выдачи, вероятность, количество и способ присоединения лута требуют отдельной задачи на проектирование и реализацию.

## Идея 3. Информационное сообщение «Зенит сообщает»

Статус:

- `ИДЕЯ`;
- `ТРЕБУЕТ ИССЛЕДОВАНИЯ`;
- `НЕ РЕАЛИЗОВАНО`.

В будущем предлагается выводить атмосферное игровое сообщение о появлении или обнаружении крупной миграционной группы.

Концепция сообщения:

> Зенит сообщает: возле `<название поселения>` наблюдается большое скопление заражённых, движущееся в направлении `<направление / название поселения>`.

Игроки должны получать предупреждение о движении большой группы заражённых в определённой части карты.

Перед реализацией необходимо определить:

- момент отправки сообщения;
- получателей: всех игроков или только игроков в определённой зоне;
- механизм вывода: UI, notification или chat;
- источник названия ближайшего поселения;
- способ определения направления движения;
- сообщать точную цель или только приблизительное направление;
- нужна ли случайная задержка;
- может ли информация быть приблизительной или неполной.

Код уведомлений в рамках этой идеи пока не создан.

## Общее правило статуса

Перенос идеи в реализацию выполняется только отдельной задачей после необходимых исследований и согласования конфигурации. До этого все перечисленные возможности считаются не реализованными независимо от полноты их описания в документе.
