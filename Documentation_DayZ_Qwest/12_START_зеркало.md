# 12_START_зеркало

Краткое зеркало текущего `Documentation/SplitDoc/START.md`.

Полный рабочий оригинал пока находится в:

- `Documentation/SplitDoc/START.md`

## Что читать всегда

Перед любой задачей читать:

- `Documentation/AGENT_TASK_LOOP.md`
- `Documentation/SplitDoc/START.md`

Дополнительные `SplitDoc` читать выборочно по матрице из `AGENT_TASK_LOOP.md`.

## Выборочное чтение

ChatGPT является маршрутизатором чтения правил:

- определяет тему задачи;
- выбирает минимальный набор тематических `SplitDoc`;
- указывает эти документы в разделе `Читать`;
- не указывает все `SplitDoc` подряд без необходимости;
- не копирует постоянные правила внутрь `БЛОКА 1`, если достаточно ссылки на `START.md` или профильный `SplitDoc`.

Агент читает только:

- `Documentation/AGENT_TASK_LOOP.md`;
- `Documentation/SplitDoc/START.md`;
- тематические документы, прямо указанные в текущем `БЛОКЕ 1`.

## Роли

Пользователь принимает финальные решения, проверяет результат в игре и на сервере, контролирует Git.

ChatGPT формирует безопасные задачи, готовит `БЛОК 1`, даёт review и помогает выделять новые постоянные правила.

Агент читает текущую задачу из `БЛОКА 1`, выполняет только её и возвращает отчёт в чат.

## Жёсткие рамки

Агент не делает инициативных правок, не чинит соседние проблемы “заодно”, не расширяет задачу самостоятельно и меняет только то, что прямо указано в `БЛОКЕ 1`.

Если проблема найдена вне текущего scope, агент фиксирует её в отчёте, но не исправляет без отдельной задачи.

## Git / REVIEW

Git контролирует только пользователь.

Подробные правила находятся в:

- `Documentation/SplitDoc/GIT_REVIEW_RULES.md`
