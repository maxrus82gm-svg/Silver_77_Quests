# Silver_77_Quests - Система квестов для DayZ

Полнофункциональная система квестов с UI, триггерами и настройкой через JSON.

## Текущая split-структура

Основная разработка теперь разделена на две корневые папки:

- `Silver_77_Quests_Client` - клиентский мод для Workshop;
- `Silver_77_Quests_Server` - приватный серверный мод для `-serverMod`.

Старые `scripts/`, `gui/` и `config.cpp` в корне оставлены как резервная монолитная версия.

## Установка

1. Скопируй `@Silver_77_Quests_Client` и `@Silver_77_Quests_Server` в папку с модами сервера
2. Добавь в параметры запуска сервера:
```
-mod=@Silver_77_Quests_Client
-serverMod=@Silver_77_Quests_Server
```
3. Запусти сервер - готово!

Мод автоматически создаст конфиг с 2 примерами квестов в `profiles/Silver_77_Quests/`

## Возможности

✅ Квесты с целями (сбор предметов)
✅ Выдача предметов при взятии квеста
✅ Награды за выполнение
✅ Повторяемые квесты с cooldown
✅ Триггерные зоны с координатами
✅ UI меню (открывается на F)
✅ Настройка через JSON
✅ Сохранение прогресса игроков

## Быстрый тест

1. Запусти сервер
2. Зайди в игру
3. Подойди к NPC/триггеру
4. Нажми F - откроется меню квестов
