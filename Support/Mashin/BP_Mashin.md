# BP_Mashin — учебная физическая машинка на Blueprint

## Цель

Сделать учебный транспорт на Blueprint:

- персонаж сможет садиться в машинку;
- управление будет передаваться Pawn-машине;
- корпус будет физическим объектом;
- колёса будут иметь точки подвески;
- позже колёса будут визуально крутиться;
- машинка будет вести себя ближе к вездеходу, а не к гоночной машине.

---

## 1. Тип Blueprint

Машинку создаём как `Pawn`, а не как `Actor`.

Причина:

- `Pawn` может получать управление от `Player Controller`;
- в него проще “посадить” персонажа;
- `Actor` тоже можно двигать через Blueprint, но для управляемого транспорта `Pawn` подходит лучше.

Blueprint:

```text
BP_CubeCar
Parent Class: Pawn


2. Корпус машины

В BP_CubeCar добавляем компонент:

Static Mesh
Name: Body
Mesh: Cube

Размер корпуса:

Scale X = 3.0
Scale Y = 1.5
Scale Z = 0.5

Мы немного удлинили платформу по X, чтобы машинка была устойчивее и больше походила на вездеход.

3. Физика корпуса

Физику включаем именно на компоненте Body, потому что двигаться должен корпус машины.

Настройки Body:

Simulate Physics = true
Mass = 800
Linear Damping = 0.8
Angular Damping = 3.0
Что значат параметры

Linear Damping — сопротивление линейному движению.
Чем выше значение, тем быстрее объект теряет скорость и меньше скользит.

Angular Damping — сопротивление вращению.
Чем выше значение, тем меньше объект крутится и переворачивается как юла.

Для вездехода полезно:

не слишком маленький Linear Damping, чтобы не было ощущения льда;
более высокий Angular Damping, чтобы корпус был устойчивее.


4. Точки колёс

Колёса сначала делаем не мешами, а точками.

Добавляем 4 компонента:

Scene Component
Wheel_FL
Wheel_FR
Wheel_RL
Wheel_RR

Расшифровка:

FL = Front Left
FR = Front Right
RL = Rear Left
RR = Rear Right

Scene Component — это не отдельная сцена, а пустая точка/трансформ внутри актора.
Таких компонентов может быть сколько угодно.

Они нужны как:

точки колёс;
точки подвески;
места для Line Trace;
места приложения силы.

5. Важная заметка про иерархию

Если Wheel_FL, Wheel_FR, Wheel_RL, Wheel_RR являются дочерними компонентами Body, то их координаты считаются относительно Body.

Это называется Relative Location.

Важно учитывать масштаб родителя:

Body Scale = 3.0 / 1.5 / 0.5

Если родитель масштабирован, дочерние точки могут визуально смещаться не так, как ожидается.

Правило:

если компонент уехал не туда —
проверь Parent, Relative Transform и Scale родителя

. Примерные позиции точек колёс

Для корпуса с длиной Scale X = 3.0 можно начать с таких значений:

Wheel_FL: X = 140,  Y = -70, Z = -40
Wheel_FR: X = 140,  Y =  70, Z = -40
Wheel_RL: X = -140, Y = -70, Z = -40
Wheel_RR: X = -140, Y =  70, Z = -40

Эти значения можно подстроить визуально.

Главное:

точки должны быть примерно у нижних углов корпуса;
передние точки находятся по +X;
задние точки находятся по -X;
левая/правая сторона расходятся по Y;
Z находится ниже корпуса.
