# AGENT TASK LOOP

Файл для управления задачами агента.

Главная идея:
- ChatGPT ставит задачу
- пользователь вставляет задачу в этот файл
- агент читает задачу
- агент возвращает отчёт в чат
- пользователь присылает отчёт ChatGPT
- ChatGPT даёт проверку и следующую задачу
- пользователь вручную обновляет этот файл

Этот файл — рабочий журнал взаимодействия:

- пользователь
- ChatGPT
- Kiro / агент
- проект `Silver_77_Quests`

Главная цель файла:
- хранить текущую задачу
- хранить последний отчёт агента
- хранить последний review ChatGPT
- хранить правила работы
- хранить историю задач
- хранить пользовательские подсказки по UI и смыслу

--------------------------------------------------------------------------------
ОБЩИЙ ПРОЦЕСС:
--------------------------------------------------------------------------------

1. ChatGPT формирует задачу
2. Пользователь вставляет задачу в БЛОК 1
3. Агент читает БЛОК 1
4. Агент выполняет задачу
5. Агент возвращает отчёт в чат
6. Пользователь отправляет отчёт ChatGPT
7. ChatGPT проверяет отчёт
8. ChatGPT даёт:
   - чистый AGENT REPORT для БЛОКА 2
   - REVIEW для БЛОКА 3
   - следующую задачу для БЛОКА 1
9. Пользователь вручную обновляет файл
10. Git commit / push делает только пользователь

--------------------------------------------------------------------------------
КТО ЗА ЧТО ОТВЕЧАЕТ:
--------------------------------------------------------------------------------

Пользователь:
- принимает финальные решения
- проверяет результат в игре
- контролирует Git
- делает commit / push
- даёт визуальные и смысловые подсказки

ChatGPT:
- ставит задачи
- формирует безопасные инструкции
- проверяет отчёты агента
- пишет REVIEW
- следит за архитектурой, рисками и порядком задач
- помогает вести этот файл

Агент / Kiro:
- читает текущую задачу
- выполняет только указанную задачу
- возвращает отчёт в чат
- не пишет отчёт в этот файл
- не делает commit / push

ПРАВИЛО ПРОВЕРКИ АКТУАЛЬНОЙ ВЕРСИИ ДЛЯ CHATGPT:
--------------------------------------------------------------------------------

Перед анализом `Documentation/AGENT_TASK_LOOP.md` ChatGPT должен:

1. Сначала проверить последний коммит ветки `main`
2. Сообщить пользователю:
   - короткий SHA коммита
   - название коммита
3. Читать `Documentation/AGENT_TASK_LOOP.md` именно из этого коммита, а не из кешированной версии `main`
4. В начале ответа писать:

   `Читаю коммит: <SHA> — <название коммита>`

5. Если пользователь видит, что коммит неактуальный, он сообщает актуальное название или SHA последнего коммита

ВАЖНО:
В проекте используется русскоязычный текст. Кириллицу нельзя повреждать.

Некоторые файлы могут быть сохранены не в UTF-8, а в CP1251 или другой Windows-кодировке.

Особенно осторожно работать с файлами:

- `.layout`
- `.json`
- `.md`
- `.c`
- `.cpp`
- `.txt`
- `.xml`

--------------------------------------------------------------------------------
ПРАВИЛА:
--------------------------------------------------------------------------------

1. НЕ перекодировать файлы без отдельной задачи
2. НЕ сохранять файл заново, если задача только аналитическая
3. НЕ заменять кириллицу на `????`, `�����` или транслит
4. НЕ “чинить” русские строки автоматически
5. Перед изменением файла с кириллицей нужно определить его текущую кодировку
6. Если кириллица отображается как `�����`, это НЕ значит, что текст надо переписать
7. Если кодировка непонятна — остановиться и написать в PROBLEMS
8. Любые правки текста с кириллицей делать только после отдельного подтверждения
