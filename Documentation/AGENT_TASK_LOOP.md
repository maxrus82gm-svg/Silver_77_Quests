# AGENT TASK LOOP

Документ для постановки задач агенту, получения его отчётов и проверки через ChatGPT.

Рабочий режим:
- ChatGPT формирует CURRENT TASK и REVIEW
- пользователь вставляет CURRENT TASK в этот файл
- агент читает CURRENT TASK
- агент возвращает отчёт в чат
- пользователь передаёт отчёт ChatGPT
- ChatGPT проверяет отчёт и даёт REVIEW + следующую задачу
- пользователь вручную вставляет чистый AGENT REPORT и REVIEW в этот файл
