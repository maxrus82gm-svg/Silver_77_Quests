# AGENT TASK LOOP

Файл для управления задачами агента.

Главная идея:
- ChatGPT ставит задачу
- пользователь вставляет задачу в этот файл
- агент читает задачу
- агент возвращает отчёт в чат
- пользователь присылает отчёт ChatGPT
- ChatGPT даёт проверку и следующую задачу
- пользователь вручную обновляет этот файл

## НАЧАЛО ЗАДАЧИ

TASK 006 — Проверка корневой папки gui без изменений

Цель:
Понять, является ли корневая папка `gui/` актуальной, резервной копией или остатком старой монолитной версии.

Где смотреть:
- gui/
- gui/QuestJournal.layout
- gui/QuestMenu.layout
- Silver_77_Quests_Client/gui/
- Silver_77_Quests_Client/gui/QuestJournal.layout
- Silver_77_Quests_Client/gui/QuestMenu.layout
- Silver_77_Quests_Client/gui/layouts/

Что сделать:
1. Проверить содержимое корневой папки `gui/`
2. Проверить содержимое `Silver_77_Quests_Client/gui/`
3. Сравнить корневые layout-файлы с layout-файлами в клиентской папке
4. Определить:
   - корневая `gui/` актуальная или старая
   - совпадает ли она с клиентской `gui/`
   - есть ли уникальные layout-файлы, которых нет в клиентской версии
   - есть ли уникальная информация, которую нельзя потерять
5. Вернуть отчёт в чат

Важно:
- ничего не изменять
- ничего не удалять
- ничего не переносить
- задача только аналитическая

Критерии готовности:
- понятно назначение корневой папки `gui/`
- понятно, совпадает ли она с `Silver_77_Quests_Client/gui/`
- понятно, есть ли в ней уникальные данные
- отчёт возвращён в чат
