# Silver_77_Quests_Client

Client-side part of Silver 77 Quests.

Publish this mod in Steam Workshop. It contains UI, layouts, key handling, shared data structures, and RPC requests.

Run on server with:

```bat
-mod=@Silver_77_Quests_Client
```

Pair it with the private server-side mod:

```bat
-serverMod=@Silver_77_Quests_Server
```
